# طبقه ۱۶ — متن و خلاصهٔ هوشمند پادکست

نسخهٔ وب سامانهٔ فارسی رونویسی، فصل‌بندی، خلاصه‌سازی و تحلیل اپیزودهای پادکست طبقه ۱۶ با Gemini.

این مخزن، سورس همان نسخه‌ای است که در نشانی زیر منتشر شده است:

https://tabaghe16-ai-notes.aid-ai.chatgpt.site

## قابلیت‌ها

- دریافت خودکار فهرست اپیزودها از RSS پادکست
- بارگذاری مستقیم فایل صوتی در Gemini Files API
- رونویسی قطعه‌ای با تایم‌کد و تشخیص گوینده
- تلاش مجدد خودکار برای خطاهای موقت و ازدحام مدل
- استفاده از مدل جایگزین در صورت در دسترس نبودن مدل اصلی
- ساخت خلاصهٔ مدیریتی، نکات کلیدی، تحلیل عمیق و درس‌های کاربردی
- فصل‌بندی اپیزود بر اساس زمان
- دانلود متن، Markdown و بستهٔ کامل خروجی
- نگهداری API Key فقط در نشست مرورگر یا متغیر محیطی سرور

## معماری

| بخش | فناوری |
| --- | --- |
| رابط کاربری | React 19 + Next.js/Vinext + TypeScript |
| API | Route Handlerهای Next/Vinext |
| مدل هوش مصنوعی | Gemini API |
| میزبانی فعلی | ChatGPT Sites / Cloudflare Workers |
| دریافت اپیزودها | RSS پادکست از Acast |

کد رابط اصلی در `app/page.tsx` و مسیرهای API در `app/api/` قرار دارند.

## پیش‌نیازها

- Node.js نسخهٔ `22.13.0` یا جدیدتر
- npm
- یک API Key معتبر از [Google AI Studio](https://aistudio.google.com/app/apikey)

## اجرای محلی

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/YOUR_USERNAME/tabaghe16-ai-notes.git
cd tabaghe16-ai-notes
npm ci
```

سپس یکی از دو روش زیر را انتخاب کنید.

### روش ۱: ورود کلید در رابط کاربری

```bash
npm run dev
```

مرورگر را روی نشانی نمایش‌داده‌شده در ترمینال باز کنید و API Key را در بخش «تنظیم موتور» وارد کنید. کلید در مخزن ذخیره نمی‌شود.

### روش ۲: متغیر محیطی سرور

فایل `.env.local` بسازید:

```env
GEMINI_API_KEY=your_key_here
```

سپس اجرا کنید:

```bash
npm run dev
```

هرگز فایل `.env.local` یا کلید واقعی را در Git commit نکنید.

## امنیت و حریم خصوصی

- هیچ API Key، فایل صوتی، متن پیاده‌سازی‌شده یا خروجی خصوصی در این مخزن قرار ندارد.
- فایل‌های `.env*` به‌جز نمونهٔ خالی، توسط `.gitignore` مسدود شده‌اند.
- پیش از عمومی‌کردن مخزن، راهنمای [امنیت](SECURITY.md) را بخوانید.
- پردازش صوت این نسخه توسط Gemini انجام می‌شود؛ بنابراین سیاست‌های دادهٔ سرویس Google نیز اعمال می‌شوند.
